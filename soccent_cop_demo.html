Graph & Dependency Analysis
Drag nodes to pin · Scroll to zoom · Click to highlight · Double-click to unpin
● DEPENDS_ON
Capability A cannot function without Capability B. If B is lost or degraded, A degrades automatically. Follow these edges to trace cascade effects.
● ENABLES
Capability A multiplies the effectiveness of B. If A is present, B performs at full capacity. Losing A degrades B's output without eliminating it.
● SHARES_PLATFORM
Two capabilities run on the same platform or system. A procurement decision, damage, or supply gap affects both simultaneously.

How to Use This Graph
The logistics network shows how supply reaches each site. Large dark circles are sites — stroke color shows DOS status (green/amber/red). Small squares are supply routes. Red triangles are chokepoint risks.
Click a RED site → see its supply line exposure and what risk nodes are connected

Scroll to zoom · Drag node to pin · Double-click to unpin
Each node is a capability. Edges show structural dependencies between them — if an upstream capability is lost, everything downstream degrades.
Red edge (DEPENDS_ON) → A cannot function without B. Trace upstream to find single points of failure.
Green edge (ENABLES) → A multiplies B. Losing A degrades but doesn't eliminate B.
Blue edge (SHARES_PLATFORM) → One procurement/supply decision affects both capabilities simultaneously.
Teal edge + [GEO] nodes → Geographic chokepoints. Hormuz closure cuts capabilities connected via teal edges.
